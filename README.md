# Distance Calculator Program

## Description
This program coverts the distance from kilometers into miles

## How to Run
1. Open the program file in VS Code, OnlineGDB,or programiz
2. Run the program
3. Enter the distance in kilometers
4. Check whether the distance is converted into miles

## Input Needed
- distance

## Sample Output
Enter distance: 100 kilometers
100 kilometers is 62.1371 miles
